# Data Directory

## Project Overview
This folder contains the dataset used for the **Global Music Streaming Listener Preferences** project. The dataset is analyzed using Python to explore music-listening behavior, streaming platform preferences, user engagement, and subscription patterns.

## Dataset Details
- **Dataset Name:** Global_Music_Streaming_Listener_Preferences.csv
- **Total Records:** 5,000
- **Original Features:** 12 columns
- **Data Format:** CSV (Comma-Separated Values)
- **Analysis Tool:** Python (Pandas, NumPy, Matplotlib, Seaborn)

## Key Features
The dataset includes information on:
- User demographics, including age and country
- Streaming platforms and preferred music genres
- Daily streaming duration and number of songs liked
- Most-played artists
- Subscription type (Free or Premium)
- Listening time (Morning, Afternoon, or Night)
- Discover Weekly engagement and repeat song rate

## Data Preparation
The analysis includes identifying categorical and numerical features and removing the `User_ID` column where it is unnecessary for exploratory data analysis.

## File Structure
- `Global_Music_Streaming_Listener_Preferences.csv` — Original dataset used for analysis.

## Usage
Place the CSV dataset in this folder and update the notebook's file path accordingly before running the analysis.

**Note:** Ensure the dataset is included in the repository if you have permission to redistribute it. If the CSV is not uploaded, this README describes the expected file rather than a file currently stored in the folder.
